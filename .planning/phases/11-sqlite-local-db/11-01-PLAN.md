# Phase 11: SQLite Local Database - Plan

**Created:** 2026-08-12
**Mode:** mvp
**Requirements:** OFFL-01, OFFL-02, NFR-11, NFR-12, NFR-13, NFR-16

## Wave 1: Install & Setup

### Task 1: Install expo-sqlite
- Run: `npx expo install expo-sqlite`
- Verify Expo Go compatibility (bundled in SDK 57)

## Wave 2: Database Schema

### Task 2: Create database module
- File: `src/db/database.ts` (new)
- Initialize expo-sqlite database connection
- Create tables on first run (entries, categories, scheduledEntries, syncQueue)
- Export database instance

### Task 3: Define SQLite schema
- Table: `entries` — id TEXT PK, uid TEXT, type TEXT, amountCents INTEGER, categoryId TEXT, date TEXT, description TEXT, createdAt INTEGER, updatedAt INTEGER, synced INTEGER DEFAULT 0
- Table: `categories` — id TEXT PK, uid TEXT, type TEXT, name TEXT, icon TEXT, createdAt INTEGER, synced INTEGER DEFAULT 0
- Table: `scheduledEntries` — id TEXT PK, uid TEXT, type TEXT, amountCents INTEGER, categoryId TEXT, date TEXT, description TEXT, frequency TEXT, endDate TEXT, lastGenerated TEXT, isActive INTEGER DEFAULT 1, createdAt INTEGER, synced INTEGER DEFAULT 0
- Table: `syncQueue` — id INTEGER PK AUTOINCREMENT, collection TEXT, docId TEXT, operation TEXT, timestamp INTEGER

### Task 4: Create entries CRUD module
- File: `src/db/entries.ts` (new)
- Functions: `getAllEntries(uid)`, `getEntriesByType(uid, type)`, `insertEntry(entry)`, `updateEntry(id, changes)`, `deleteEntry(id)`, `getUnsyncedEntries()`, `markSynced(id)`
- All functions operate on SQLite

### Task 5: Create categories CRUD module
- File: `src/db/categories.ts` (new)
- Functions: `getAllCategories(uid)`, `getCategoriesByType(uid, type)`, `insertCategory(cat)`, `updateCategory(id, changes)`, `deleteCategory(id)`, `getUnsyncedCategories()`, `markSynced(id)`

### Task 6: Create scheduled entries CRUD module
- File: `src/db/scheduled.ts` (new)
- Functions: `getAllScheduled(uid)`, `getActiveScheduled(uid)`, `insertScheduled(entry)`, `updateScheduled(id, changes)`, `deleteScheduled(id)`, `getUnsyncedScheduled()`, `markSynced(id)`

### Task 7: Create sync queue module
- File: `src/db/syncQueue.ts` (new)
- Functions: `enqueue(collection, docId, operation)`, `dequeue(id)`, `getQueue()`, `clearQueue()`, `removeByDocId(collection, docId)`

## Wave 3: Migration / Seed

### Task 8: Create Firestore seed function
- File: `src/db/seed.ts` (new)
- Function: `seedFromFirestore(uid)` — fetches all entries, categories from Firestore and inserts into SQLite
- Checks if SQLite already has data for this uid (idempotent — skip if already seeded)
- Called on first sign-in or new device

### Task 9: Wire database init into App.tsx
- File: `App.tsx`
- On auth state change: if user signed in, check if SQLite has data for uid
- If empty → call seedFromFirestore(uid)
- If populated → skip (offline-ready)

## Wave 4: Verify

### Task 10: Run typecheck + lint
- Run `npx tsc --noEmit`
- Fix any type errors

### Task 11: Manual verification
- Sign in → SQLite should be seeded with Firestore data
- Kill app → reopen → data should persist from SQLite (offline)
- Sign in on new device → seed should run again (idempotent)
