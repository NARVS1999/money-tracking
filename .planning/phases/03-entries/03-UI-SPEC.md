From `tokens.ts`:

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|

**Tabular-nums scope:** Entry row amounts (right side), form amount input display, and Phase 4 summary totals. NOT used on date strings or description text.

## Component Contracts

### EntriesProvider

**Type:** React Context provider (follows `CategoriesProvider` pattern exactly)

**Context value:**
```typescript
{
  entries: Entry[];
  addEntry: (data: EntryInput) => Promise<void>;
  updateEntry: (id: string, data: EntryInput) => Promise<void>;
  deleteEntry: (id: string) => Promise<void>;
  copyEntry: (source: Entry) => Promise<void>;
  isLoading: boolean;
}
```

**Entry type:**
```typescript
type Entry = {
  id: string;
  uid: string;
  type: 'expense' | 'income';
  amount: number; // integer cents
  categoryId: string;
  date: string; // 'YYYY-MM-DD'
  description: string; // ≤200 chars
  createdAt: Timestamp;
  hasPendingWrites?: boolean; // derived from Firestore metadata
};
```

**Subscription:** Single `onSnapshot` on `entriesByType(uid, type)` per tab. Provider wraps both tabs so both share one subscription set (expenses + income). Listens to `doc.metadata.hasPendingWrites` and `doc.metadata.fromCache` for sync indicators.

**Error handling:** Every write (`addEntry`, `updateEntry`, `deleteEntry`) wrapped in `.catch()` → exposes `lastError` in context for toast display. Auto-clears after 5 seconds.

### EntryRow

**Layout:** Horizontal `View` with `flexDirection: 'row'`, `alignItems: 'center'`, `minHeight: 44`.

**Left side:** `flex: 1` column:
- Row 1: Category name (`body` 16px, `textPrimary`, `numberOfLines={1}`)
- Row 2: Date string + description (`label` 14px, `textSecondary`, `numberOfLines={1}`)

**Right side:** Column, `alignItems: 'flex-end'`:
- Amount (`display` 44px weight 700, `tabular-nums`, color = `income` or `expense` based on entry type)
- Below amount (when syncing): Red dot (4px circle `#DC2626`) + "Syncing…" text (`label` 14px `textSecondary`)

**Separator:** 1px `#E5E7EB` bottom border (not a separate component — inline `borderBottomWidth`)

**Swipeable wrapper:** `react-native-gesture-handler` `Swipeable`, same pattern as `CategoriesScreen`. Three right actions: Edit (grey), Copy (grey), Delete (red).

### EntryForm

**Presentation:** Modal (`presentation: 'modal'` in native-stack). Full-screen white background.

**Layout (top to bottom):**
1. **Header bar:** "Cancel" left (text, `textSecondary`), title center ("Add Entry" / "Edit Entry" / "Copy Entry"), "Save" right (text, `accent` color, bold)
2. **Amount display:** Large `tabular-nums` display (44px, weight 700, centered). Live-updates as user types raw digits. Shows "₱ 0.00" when empty.
3. **Amount input:** `TextInput` with `keyboardType: 'decimal-pad'`. Hidden — focused by default on open. User types raw digits, `parsePesoInput()` converts to cents, `formatCents()` displays above.
4. **Category picker:** Label "Category" above, then a tappable row showing selected category name. `@react-native-community/datetimepicker`-style bottom sheet for category selection. Lists only the current tab's categories from CategoriesProvider.
5. **Date picker:** Label "Date" above, then a tappable row showing formatted date. Opens native `@react-native-community/datetimepicker` with `maximumDate={new Date()}` (ENTR-04). Defaults to today.
6. **Description input:** Label "Description (optional)" above. `TextInput`, single line, `maxLength: 200`, `placeholder: "What was this for?"`.
7. **Keyboard spacer:** `KeyboardAwareScrollView` from `react-native-keyboard-controller` wraps the form content.

**Pre-fill modes:**
- **Add:** Empty form, date = today, amount = 0
- **Edit:** Pre-fill all fields from existing entry, date = entry's date
- **Copy:** Pre-fill category, amount, description from source. Date = today (ENTR-08). Saves as new entry (different doc ID).

**Validation:**
- Amount must be > 0 (₱0.00 is invalid)
- Category must be selected
- Save button disabled when amount = 0 or no category selected

### DateSectionHeader

**Layout:** `View` with `paddingHorizontal: spacing.md`, `paddingVertical: spacing.sm`, `backgroundColor: colors.background`.

**Text:** `label` 14px, weight 700, `textSecondary`, `accessibilityRole="header"`.

**Date labels:**
- Today's date → "Today"
- Yesterday → "Yesterday"
- Older → formatted as "Aug 7" (month abbreviated, day number)

## Offline Sync Indicator

**Per-entry indicator:**
- Visible when `entry.hasPendingWrites === true` (Firestore metadata)
- Rendered as: 4px red dot + "Syncing…" text on a new line below the date/description
- Disappears automatically when Firestore confirms the write (listener fires with `hasPendingWrites: false`)

**Error state:**
- `.catch()` on every write operation
- On failure: `lastError` set in EntriesProvider context
- Toast banner appears at top of screen: "Save failed — retry?" with "Retry" tappable text
- Retry re-attempts the failed operation
- Auto-dismiss after 5 seconds

**Reconnect behavior:**
- Firestore `onSnapshot` automatically reconciles on reconnect
- No user action needed — indicators disappear and data syncs
- No manual "retry" or "refresh" affordance

## Entry Form Amount Input

**Raw input approach (from CONTEXT.md):**
1. User types raw digits into `TextInput` with `keyboardType: 'decimal-pad'`
2. `parsePesoInput()` from `src/lib/money.ts` converts to integer cents
3. `formatCents()` displays formatted amount above input
4. Display shows "₱ 2,450.00" as user types "2450"

**Input rules:**
- Strip non-digit characters (except `.` for decimal)
- Max 2 decimal places
- Leading zeros allowed during typing (e.g., "0.50" → 50 cents)
- Empty input → display shows "₱ 0.00"
- Amount > 999,999.99 rejected (formatting overflow)
