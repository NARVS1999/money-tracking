Create the EntryForm modal and wire it to both tabs via FAB navigation.

1. Create `src/components/EntryForm.tsx`. This is a full-screen modal form. Props: `{ mode: 'add' | 'edit' | 'copy', type: 'expense' | 'income', entryId?: string, prefill?: Partial<EntryInput>, onSave: () => void, onCancel: () => void }`.

   Layout (top to bottom):
   - Header bar: "Cancel" left (text, textSecondary), title center ("Add Entry" / "Edit Entry" / "Copy Entry"), "Save" right (text, accent color, bold). Save calls addEntry (add mode) or updateEntry (edit/copy mode) from useEntries().
   - Amount display: Large tabular-nums display (44px, weight 700, centered). Live-updates as user types raw digits. Shows "₱ 0.00" when empty. Use formatCents() from src/lib/money.ts.
   - Amount input: TextInput with keyboardType="decimal-pad". Hidden but focused by default on open (ref). User types raw digits, parsePesoInput() converts to cents, formatCents() displays above.
   - Category picker: Label "Category" above, then a tappable row showing selected category name. Use a simple modal/bottom sheet for category selection — list categories from useCategories() filtered by tab type (expense tab → expenseCategories, income tab → incomeCategories). Selected category highlighted.
   - Date picker: Label "Date" above, then a tappable row showing formatted date. Use @react-native-community/datetimepicker with maximumDate={new Date()} (ENTR-04). Defaults to today(). On Android, date picker opens inline. On iOS, opens as modal.
   - Description input: Label "Description (optional)" above. TextInput, single line, maxLength: 200, placeholder: "What was this for?".
   - KeyboardAwareScrollView from react-native-keyboard-controller wraps the form content.

   Pre-fill modes:
   - Add: Empty form, date = today(), amount = 0
   - Edit: Pre-fill all fields from existing entry (look up by entryId from entries array)
   - Copy: Pre-fill category, amount, description from source. Date = today() (ENTR-08). Saves as new entry.

   Validation:
   - Amount must be > 0 (₱0.00 is invalid)
   - Category must be selected
   - Save button disabled when amount = 0 or no category selected

2. Register EntryForm as a modal screen in `App.tsx`. Add to the Stack.Navigator: `<Stack.Screen name="EntryForm" component={EntryForm} options={{ presentation: 'modal', headerShown: false }} />`. The screen receives params via route.params.

3. Wire FAB navigation in `src/screens/ExpensesScreen.tsx` and `src/screens/IncomeScreen.tsx`. Import `useNavigation` from `@react-navigation/native`. FAB onPress: `navigation.navigate('EntryForm', { mode: 'add', type: 'expense' })` (or 'income' for IncomeScreen).
