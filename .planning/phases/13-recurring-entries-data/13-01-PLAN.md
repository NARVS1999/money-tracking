## Wave 2: Frequency Utilities

### Task 3: Create frequency matching utilities
- File: `src/lib/frequency.ts` (new)
- Function: `matchesFrequency(date, frequency, startDate)` — check if a date matches the frequency pattern starting from startDate
  - `once`: date === startDate
  - `daily`: always matches (every day)
  - `weekly`: (date - startDate) % 7 === 0
  - `monthly`: date.getDate() === startDate.getDate()
  - `yearly`: date.getDate() === startDate.getDate() && date.getMonth() === startDate.getMonth()
- Function: `getNextDate(lastDate, frequency)` — calculate next occurrence date
- Function: `formatFrequency(frequency)` — human-readable label ("Once", "Daily", "Weekly", "Monthly", "Yearly")

### Task 4: Extend dates.ts
- File: `src/lib/dates.ts`
- Add: `isSameDay(a, b)` — compare two date strings
- Add: `daysBetween(a, b)` — difference in days
- Add: `addMonths(s, n)` — add n months to date string
- Add: `addYears(s, n)` — add n years to date string

## Wave 3: Auto-Generation Engine

### Task 5: Create scheduler engine
- File: `src/scheduled/scheduler.ts` (new)
- Function: `runScheduler(uid)` — main entry point, called on app startup
  - Fetch all active scheduled entries from SQLite
  - For each: determine dates to generate (from lastGenerated/date to today)
  - For each date: create Entry in SQLite + enqueue sync
  - Update lastGenerated in SQLite
- Function: `getDatesToGenerate(scheduledEntry, today)` — returns array of date strings
  - `once`: [date] if not yet generated, else []
  - `daily`: all dates from lastGen to today
  - `weekly`: every 7 days from lastGen to today
  - `monthly`: month boundaries from lastGen to today
  - `yearly`: year boundaries from lastGen to today
- Function: `generateEntry(scheduledEntry, date)` — create EntryInput from scheduled entry + specific date

### Task 6: Wire scheduler on app startup
- File: `App.tsx` or `src/scheduled/ScheduledEntriesProvider.tsx`
- After entries + categories are loaded, call `runScheduler(uid)`
- Scheduler runs in background (not blocking UI)
- Generated entries appear in entries list automatically
