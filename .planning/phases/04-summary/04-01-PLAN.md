3. Replace `src/screens/HomeScreen.tsx` with a real screen. Import `useEntries` from `src/entries/EntriesProvider.tsx`, `useCategories` from `src/categories/CategoriesProvider.tsx`, `monthRange` and `today` from `src/lib/dates.ts`, `formatCents` from `src/lib/money.ts`, `colors` and `spacing` and `typography` from `src/theme/tokens.ts`, `SummaryTotals` and `CategorySection`. Use `useMemo` from React for derivation logic.

   Derivation logic in HomeScreen:
   - Compute `{ start, end }` from `monthRange(today())`
   - Filter entries to current month: `entries.filter(e => e.date >= start && e.date <= end)` — memoized on `[entries, start, end]`
   - Compute expenseTotal: sum of `e.amount` where `e.type === 'expense'` — memoized on `[monthEntries]`
   - Compute incomeTotal: same for income
   - Compute expenseBreakdown: group monthEntries by categoryId where type === 'expense', sum amounts per category, resolve name via expenseCategories.find(c => c.id === categoryId)?.name || 'Unknown', sort by amount descending — memoized on `[monthEntries, expenseCategories]`
   - Compute incomeBreakdown: same for income — memoized on `[monthEntries, incomeCategories]`
   - Month label: compute from `today().split('-')` — use monthNames array `['January', 'February', ...]` to get `'MMMM YYYY'` format

   Layout (top to bottom, ScrollView):
   - SafeAreaView (top inset)
   - Month header Text: "August 2026" — heading style (20px, weight '700', textPrimary), `paddingHorizontal: spacing.md`, `paddingTop: spacing.lg`, `paddingBottom: spacing.sm`
   - SummaryTotals component with expenseCents/incomeCents props
   - Divider: View with `height: 1`, `backgroundColor: colors.border`, `marginHorizontal: spacing.md`
   - If expenseBreakdown.length > 0: CategorySection with title="Expenses", rows=expenseBreakdown, color=colors.expense, subtotalCents=expenseTotal
   - If incomeBreakdown.length > 0: CategorySection with title="Income", rows=incomeBreakdown, color=colors.income, subtotalCents=incomeTotal
   - SafeAreaView (bottom inset)

   The screen uses `ScrollView` (not FlatList) since the content is short and doesn't need virtualization. `contentContainerStyle: { flexGrow: 1, backgroundColor: colors.background }`.
