**Mode:** mvp
**Requirements:** BDGT-01, BDGT-02, BDGT-03, BDGT-04, BDGT-05, BDGT-06, BDGT-07, NFR-08

## Wave 1: Data Layer

Extend the data model and provider to support budget CRUD.

### Task 1: Extend UserProfile type
- File: `src/auth/AuthProvider.tsx`
- Add optional budget fields to UserProfile: `budgetAmount?: number`, `budgetStartDate?: string`, `budgetEndDate?: string`
- Add `updateBudget(amount, startDate, endDate)` method — writes to users/{uid} doc
- Add `clearBudget()` method — removes budget fields from users/{uid} doc
- Parse budget fields from Firestore doc in the existing fetch

### Task 2: Add budget field parsing
- File: `src/auth/AuthProvider.tsx`
- In the existing `onSnapshot` callback that reads users/{uid}, extract budgetAmount, budgetStartDate, budgetEndDate
- Expose them in the userProfile context value

## Wave 2: Budget Card Component

Create the BudgetCard component for the Home screen.

### Task 3: Create BudgetCard component
- File: `src/components/BudgetCard.tsx` (new)
- Props: `budgetAmount`, `budgetStartDate`, `budgetEndDate`, `expenseCents`, `onTap`
- Shows: "Budget" label, formatted amount, date range text
- Progress bar: width = min(expenseCents / budgetAmount * 100, 100)%
- Bar color: green (#16A34A) < 70%, yellow (#F8C519) 70-90%, red (#DC2626) > 90%
- Remaining amount text below bar
- When expired: "Set new budget" prompt instead of progress bar
- Card style: white surface, rounded corners (radius.lg), shadow, orange accent border

## Wave 3: Home Screen Integration

Wire the BudgetCard into the Home screen.

### Task 4: Add BudgetCard to HomeScreen
- File: `src/screens/HomeScreen.tsx`
- Read budget from userProfile (via useAuth)
- Compute expense total within budget date range (not just current month)
- Show BudgetCard between SummaryCard and quick-action buttons
- When no budget: hide the card entirely
- Tap on budget card navigates to Account screen (budget section)

## Wave 4: Budget Settings

Add budget settings to the Account screen.

### Task 5: Add budget settings section to AccountScreen
- File: `src/screens/AccountScreen.tsx`
- New section below profile card: "Budget" section
- Shows current budget (if set): amount, date range, edit/remove buttons
- "Set Budget" button when no budget exists
- Budget form: amount input (₱, integer cents), start date picker, end date picker
- Save writes to Firestore via AuthProvider.updateBudget()
- Remove calls AuthProvider.clearBudget()
