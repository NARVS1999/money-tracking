# Phase 9: Category Icons - Plan

**Created:** 2026-08-09
**Mode:** mvp
**Requirements:** ICNS-01, ICNS-02, ICNS-03, ICNS-04, ICNS-05, ICNS-06, NFR-09

## Wave 1: Data Layer

Extend the Category type and provider to support icons.

### Task 1: Extend Category type
- File: `src/categories/CategoriesProvider.tsx`
- Add optional `icon` field to Category type: `{ id, name, createdAt, icon?: string }`
- Update `toCategory` mapper to parse `icon` from Firestore doc
- Add `icon` parameter to `addCategory(kind, name, icon?)` method
- Include `icon` in the Firestore `addDoc` call and local mirror

## Wave 2: Shared Components

Create reusable icon components.

### Task 2: Create preset icons config
- File: `src/components/categoryIcons.ts` (new)
- Export `PRESET_ICONS` array: ~20 emoji strings
- Export `ICON_COLORS` and `ICON_TEXT_COLORS` arrays (already in CategorySection, move here)

### Task 3: Create CategoryIcon component
- File: `src/components/CategoryIcon.tsx` (new)
- Props: `icon?: string`, `name: string`, `size?: number`
- If `icon` is set: render emoji in a colored rounded square
- If no `icon`: render first letter of `name` in a colored square (existing behavior)
- Use consistent colors from categoryIcons.ts

### Task 4: Create IconPicker component
- File: `src/components/IconPicker.tsx` (new)
- Props: `visible`, `onSelect(icon: string)`, `onSkip()`, `onClose()`
- Bottom sheet modal with 4-column FlatList of emoji buttons
- "Skip" button at bottom
- Each emoji is a 48x48 touchable item

## Wave 3: Screen Integration

Wire icons into existing screens.

### Task 5: Update CategoriesScreen
- File: `src/screens/CategoriesScreen.tsx`
- After adding a category, show icon picker modal
- Show CategoryIcon to left of each category name in rows
- Pass icon to `addCategory(kind, name, icon)`

### Task 6: Update CategorySection
- File: `src/components/CategorySection.tsx`
- Replace auto-generated initial-letter icons with CategoryIcon component
- Pass `icon` field from category data (need to pass full category objects instead of just name/cents)

### Task 7: Update EntryForm category picker
- File: `src/components/EntryForm.tsx`
- Add CategoryIcon to each category row in the bottom sheet modal
- Show icon next to category name in the picker list

### Task 8: Update HomeScreen
- File: `src/screens/HomeScreen.tsx`
- Pass category objects (with icon) to CategorySection instead of just name/cents
- Update expenseBreakdown/incomeBreakdown to include icon field
