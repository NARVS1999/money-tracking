### Component Breakdown

**1. Screen root**
- `ScrollView` with `style={{ flex: 1, backgroundColor: colors.background }}`
- `contentContainerStyle={{ flexGrow: 1, backgroundColor: colors.background }}`
- Horizontal padding: `spacing.md` (16px) on all content

**2. Date range section**
- Two date picker cards, vertically stacked with `gap: spacing.sm` (8px)
- Each card: white surface (`colors.surface`), 1px border (`colors.border`), `borderRadius: radius.sm` (8px), `padding: spacing.md` (16px)
- Tapping a card opens the native `@react-native-community/datetimepicker` (bundled in Expo Go)
- From picker: `maximumDate` = To date (cannot select after To)
- To picker: `minimumDate` = From date (cannot select before From)
- Both pickers: `maximumDate` = today (no future dates — consistent with entry form ENTR-04)
- Date display format: "MMM DD, YYYY" (e.g. "Aug 01, 2026") — locale-independent, matches `toDateString` output parsed for display

**3. "This Month" quick-select button**
- Row below date pickers, left-aligned
- Outline style: 1px border `colors.accent` when active, `colors.border` when inactive
- `borderRadius: radius.sm` (8px), `paddingHorizontal: spacing.md`, `paddingVertical: spacing.sm`
- `minHeight: 44` (touch target)
- Tap sets From = first day of current month, To = last day of current month (via `monthRange(today())`)
- Active state: border `colors.accent`, text `colors.accent`
- Inactive state: border `colors.border`, text `colors.textSecondary`

**4. Separator**
- 1px horizontal line, `backgroundColor: colors.border`, `marginVertical: spacing.md`

**5. Format selection buttons**
- Three buttons in a horizontal row, `gap: spacing.sm` (8px)
- Each button: `flex: 1`, `minHeight: 44`, `borderRadius: radius.sm` (8px), centered text
- Active button: `backgroundColor: colors.accent`, text `colors.onAccent` (white)
- Inactive button: `backgroundColor: colors.surface`, 1px border `colors.border`, text `colors.textPrimary`
- Button text: "PDF", "Excel", "CSV" — `fontSize: typography.body.size` (16px), `fontWeight: '600'`
- Only one button active at a time (single format export)
- Default active: none (user must select a format before export runs)

**6. Loading state**
- Below format buttons, centered
- Text: "Generating…" — `fontSize: typography.label.size` (14px), `color: colors.textSecondary`
- Format buttons remain visible but disabled (`opacity: 0.5`) during generation
- Date pickers remain interactive during generation (user can prepare next export)

**7. Empty range state**
- Below format buttons when `entriesInRange()` returns 0 entries
- Text: "No entries in this range" — centered, `fontSize: typography.label.size` (14px), `color: colors.textSecondary`
- Format buttons remain visible but tapping shows the empty state copy (no export generated)

**8. Inline date validation error**
- Shown below To picker when end date is before start date
- Text: "End date must be after start date" — `fontSize: typography.label.size` (14px), `color: colors.danger`
- Format buttons disabled until range is valid

## Interaction States

### Export Flow

| State | Trigger | Visual |
|-------|---------|--------|
| Idle | Screen loads, no format selected | Date pickers active, "This Month" outline, format buttons all inactive, no loading/empty text |
| Date changed | User taps a date picker card | Native date picker opens, card border may highlight briefly |
| "This Month" tapped | User taps quick-select | From/To snap to current month, "This Month" button becomes active (accent border) |
| Format selected | User taps PDF/Excel/CSV | Tapped button becomes active (accent bg), others remain inactive |
| Export started | User taps an active format button | Loading text appears, format buttons disabled (opacity 0.5) |
| Export success | File generated and saved/shared | Success toast appears (see Toast section), loading text disappears, format buttons re-enable |
| Export error | Generation or save fails | Error toast appears, loading text disappears, format buttons re-enable |
| Range invalid | To < From | Inline error below To picker, format buttons disabled |

### Toast Notifications

**Success toast:**
- Position: top of screen, below status bar (safe area)
- Background: `colors.surface` (white), 1px border `colors.border`, `borderRadius: radius.sm`
- Layout: green checkmark icon (✓ in `colors.income`) + heading "Saved" (16px/700) + filename (14px/400, textSecondary) + "Open" action button (accent text)
- Dismiss: auto-dismiss after 4 seconds, or tap "Open" to open the file
- Accessibility: `accessibilityRole="alert"`, `accessibilityLiveRegion="polite"`

**Error toast:**
- Position: same as success toast
- Background: same as success toast
- Layout: red ✕ icon (colors.danger) + heading "Export failed" (16px/700, colors.danger) + error copy (14px/400, textSecondary) + "Retry" action button (accent text)
- Dismiss: auto-dismiss after 6 seconds, or tap "Retry" to re-run the same export
- Accessibility: `accessibilityRole="alert"`, `accessibilityLiveRegion="assertive"`

### Date Picker Behavior

- Uses `@react-native-community/datetimepicker` (bundled in Expo Go, SDK 57)
- Mode: `"date"` (calendar picker, not time)
- `maximumDate={new Date()}` on both pickers (no future dates)
- From picker: `maximumDate` is min(today, To date)
- To picker: `minimumDate` is From date
- On change: update state, re-validate range, clear any inline error
- Platform: Android shows native dialog, iOS shows inline picker — both handled by the library
