## How to Run

```bash
# Install Maestro CLI
curl -Ls "https://get.maestro.mobile.dev" | bash

# Start Expo dev server
npx expo start

# Run all tests
npm run maestro:all

# Run specific test suites
npm run maestro:auth
maestro test .maestro/entries/
maestro test .maestro/categories/
```
