## Wave 1: Refactor EntriesProvider

### Task 1: Refactor EntriesProvider to SQLite
- File: `src/entries/EntriesProvider.tsx`
- Replace `getDocs(entriesByType(uid, type))` with `getAllEntries(uid)` from `src/db/entries.ts`

## Wave 2: Sync Service

### Task 3: Create sync service
- File: `src/sync/syncService.ts` (new)
- Function: `pushChanges(uid)` — process syncQueue items to Firestore
  - Creates: addDoc to Firestore, update local ID if temp, markSynced
  - Updates: updateDoc in Firestore, markSynced
  - Deletes: deleteDoc in Firestore, remove from SQLite
- Function: `pullChanges(uid, lastSyncTimestamp)` — fetch Firestore changes since timestamp
  - Query entries where updatedAt > lastSyncTimestamp
  - Merge into SQLite with last-write-wins
- Function: `fullSync(uid)` — push then pull, update lastSync timestamp

### Task 4: Create ID mapping utility
- File: `src/sync/idMapping.ts` (new)
- Function: `mapTempId(collection, tempId, realId)` — update references when temp ID → Firestore ID
- Function: `isTempId(id)` — check if ID is a local temp (negative number or UUID pattern)

### Task 5: Create sync metadata storage
- File: `src/sync/syncMetadata.ts` (new)
- Store lastSyncTimestamp in SQLite or AsyncStorage
- Function: `getLastSync()`, `setLastSync(timestamp)`

### Task 6: Wire auto-sync on foreground
- File: `App.tsx` or `src/sync/SyncProvider.tsx`
- Use AppState listener to detect foreground transitions
- When app comes to foreground and online → trigger fullSync()

### Task 7: Wire manual sync button
- File: `src/components/SyncButton.tsx`
