## Wave 1: Scheduled Entry Row Component

### Task 1: Create ScheduledEntryRow component
- File: `src/components/ScheduledEntryRow.tsx` (new)
- Props: scheduled entry data, onEdit, onDelete, onTogglePause
- Renders: category icon, description (or category name), amount (formatted), frequency label, next date
- Swipe actions: Edit (blue), Delete (red), Pause/Resume (grey)
- Matches existing EntryRow styling pattern

### Task 2: Create frequency label helper
- File: `src/lib/frequency.ts` (from Phase 13)
- `formatFrequency(frequency)` → "Once", "Daily", "Weekly", "Monthly", "Yearly"
- `getNextOccurrence(scheduledEntry)` → formatted date string for next occurrence

## Wave 2: Scheduled Entry Form

### Task 3: Create ScheduledEntryForm component
- File: `src/scheduled/ScheduledEntryForm.tsx` (new)
- Same base fields as EntryForm: amount, category, date, description
- Additional fields: frequency picker (segmented control), end date (shown when frequency != "once")
- Frequency picker: 5 options in a horizontal row — Once, Daily, Weekly, Monthly, Yearly
- Date field = start date (first occurrence)
- End date field = optional, only shown when frequency is not "once"
- Validates: amount > 0, category selected, date valid, endDate after startDate if provided
- On save: calls addScheduled or updateScheduled from ScheduledEntriesProvider

### Task 4: Wire form into navigation
- File: `App.tsx`
- Add `ScheduledEntryForm` as a modal screen in the Stack Navigator (same pattern as EntryForm)

## Wave 3: ExportScreen Integration

### Task 5: Add scheduled entries section to ExportScreen
- File: `src/screens/ExportScreen.tsx`
- Add "Scheduled Entries" section below existing export controls
- Section header with "Add Scheduled" button
- Two sub-sections: "Expenses" and "Income"
- Each sub-section lists scheduled entries using ScheduledEntryRow
- Sections hidden when no scheduled entries of that type exist
- Tap row → navigate to ScheduledEntryForm in edit mode
- Swipe → edit, delete, pause/resume

### Task 6: Add empty state
- When no scheduled entries exist, show an empty state message
- "No scheduled entries yet. Add one to auto-generate recurring expenses or income."
