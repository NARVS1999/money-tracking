## Summary

A personal expense/income tracker for the phone (Expo Go workflow): sign in with email/password, log entries in under 10 seconds with session-scoped offline persistence, manage per-type categories, view the current-month summary, and export date-range PDF/Excel/CSV summaries to the phone.

## Key Decisions

| Decision | Rationale | Outcome |
|----------|-----------|---------|
| Firestore only, no local SQLite | Built-in offline persistence = local-first behavior with zero sync code (ADR-0001) | Implemented |
| Email/password accounts with default | Owner wants real login identity with protected default + account create/delete (ADR-0005) | Implemented |
| Amounts as integer cents | Exact math, standard currency practice, no float errors (ADR-0003) | Implemented |
| Category deletion blocked until empty | Zero data loss; forces explicit choice; no orphaned refs (ADR-0004) | Implemented Phase 2 |
| Dates as `"YYYY-MM-DD"` strings | Timezone-safe range queries, no midnight-offset bugs | Implemented |
| Firebase JS SDK instead of native modules | Only option that runs in Expo Go | Implemented |
| expo-print + SheetJS for exports | Expo Go compatible, no native builds | Implemented |
| Session-scoped offline for MVP | Default memory cache; durable offline deferred to v2 | Implemented |
| CSV export included alongside Excel | Near-free, same pipeline | Implemented |
